# 🎂 Birthday Gift Website

A simple and interactive birthday gift website created using HTML, CSS, and JavaScript.

## ✨ Features

* Beautiful birthday-themed design
* Interactive animations and effects
* Multiple pages for a personalized experience
* Images and GIF support
* Special birthday messages

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Enjoy the birthday surprise experience.

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript

## 💝 Purpose

This project was created as a special digital birthday gift to make someone's day memorable and enjoyable.
